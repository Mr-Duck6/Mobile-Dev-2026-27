# practice2_devcard

## Опис проєкту

Проєкт являє собою одноекранний додаток-візитку розробника. У ньому реалізовано:

- Архітектуру з використанням компонентного підходу.
- Динамічне управління станом для перемикання між світлою та темною темами.
- Адаптивну стилізацію інтерфейсу за допомогою Theme.of(context), що забезпечує коректне відображення кольорів незалежно від обраної теми.

## Інструкція з запуску

1. Клонувати проект на комп'ютер.
2. Ввести у консолі flutter pub get
3. Обрати цільовий пристрій Chrome (web) для швидкого тестування або налаштований Android-емулятор.
4. Натиснути F5 у VS Code або виконавши команду: bash flutter run

## Труднощі та їх розв'язання

Під час розробки та налаштування середовища виникли кілька типових технічних труднощів, які успішно вирішено:

1. Проблема з архітектурою та дублюванням коду
   - Початкове розміщення всіх елементів контактів у головному файлі призводило до захаращення коду.
     Розв'язання: Створено окремий перевикористовуваний віджет ContactTile в окремому файлі, який приймає іконку та текст через параметри конструктора. Це зробило код чистим і модульним.

2. Зникнення підсвічування та помилки після flutter clean
   - Після очищення кешу проєкту редактор почав підсвічувати весь код червоним через втрату пакетів.
     Виконано команду flutter pub get для повторного завантаження залежностей, а також використано перезапуск аналізатора коду (Dart: Restart Analysis Server), що відновило коректну роботу середовища.

3. **Збої при підключенні Android-емулятора (ADB/NDK)**
   - Помилки збірки пов'язані з відсутністю специфічних компонентів Android NDK та зависанням процесу adb.
     Для швидкого та стабільного тестування переключено середовище виконання на Chrome (Web), що дозволило успішно перевірити всю логіку додатку та перемикання тем без навантаження на важкі мобільні емулятори.
